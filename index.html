Keyboard shortcuts

Every part of this desktop works from the keyboard. Nothing here needs a mouse, and nothing needs dragging.

Desktop and window keyboard commands
KeyDoes
TabMove between the icon grid, the open windows, and the taskbar
↑ ↓ ← →Move the selection inside the icon grid, the taskbar, or a menu
EnterOpen the selected icon, or activate the focused control
EscClose the focused window, or dismiss a menu
Alt + SpaceOpen the window menu — Restore, Move, Size, Minimize, Maximize, Close
Alt + TabSwitch to the next open window
Ctrl + EscOpen the Start menu
Ctrl + PPrint — produces a clean plain resume, not a picture of a desktop

In the window menu, Move and Size put the window into a keyboard mode: the arrow keys move or resize it, Enter commits, and Esc cancels. That is how real Windows did it, and it means dragging is never the only way to do anything here.

How this site works

The resume is real HTML in the page, written once. The desktop is a layer on top of it:

  • With JavaScript off, you get a plain, readable resume document.
  • With it on, each section of that same document is decorated into a window. The content is never copied — only re-framed.
  • Ctrl + P prints the document, not the desktop.
  • Every window has a shareable link. Adding #win-projects to the URL opens Projects directly.

Theme and font size live in Display Properties — right-click the desktop and choose Properties, or open it from the Start menu. The font-size control is there because fixed-pixel chrome doesn't respond to browser text zoom the way ordinary text does.

Colophon

Hand-written HTML, CSS and vanilla JavaScript. No frameworks, no build step, no packages, no network requests — opening the file straight off a disk works.

  • No images. The wallpaper is layered CSS gradients plus one authored SVG path. Every icon is an original SVG drawn for this site, in a single 18 KB inline sprite.
  • The window manager handles focus and z-order, pointer-capture dragging, edge resizing, maximize/restore geometry memory, taskbar semantics, hash routing, and keyboard move and size modes.
  • Type is Tahoma, the real Windows XP interface font, with a fallback stack chosen to degrade without shifting the layout.
